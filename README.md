# 🎨 MedCard QR - Frontend

> Interface web responsiva (Mobile First) do sistema de compartilhamento de informações clínicas para emergências do trabalho.

---

## 📌 Sobre o Módulo
Este repositório contém a interface da aplicação **MedCard QR**, responsável pelos formulários de cadastro de colaboradores, formulário de dados médicos, gerador visual de QR Code e a tela de consulta rápida utilizada por socorristas.

---

## 🛠️ Tecnologias Utilizadas
- **Framework:** React.js
- **Estilização:** Tailwind CSS
- **Gerador de QR Code:** qrcode.react
- **Consumo de API:** Axios / Fetch API
